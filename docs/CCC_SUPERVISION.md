## 최신 운영 지시 및 구현 — v13

명확한 추가 요구는 기록만 하고 멈추지 않고 같은 작업에서 개발·검증·승인된 PAPER 배포까지 수행한다. 문제를 찾으면 해결 대안을 비교·선택하고 처리 가능한 수정/시험/배포는 추가 지시 없이 실행한다. 보고는 **원인 → 선택한 해결 방법 → 실제 수행 결과/증거 → 남은 장애·다음 조치 → 기한 영향** 순서다. `DEADLINE_AT_RISK`나 카운트다운만 반복하지 않는다. 사용자 전용 조작·추가 비용 승인이 실제 필요할 때만 정확한 항목·이유·대안을 제시하며 독립 작업은 계속한다. Replit busy/미접수는 개발 진행 증거가 아니다. 불필요한 반복 유료 조회를 하지 않으며 비용 확인 불가는 UNKNOWN이다.

Virtual400 신규 PAPER 진입을 전략 가격 목표·실제 추정비용 기준 순손익비1.5 이상·증거금 손절 상한10%로 수정했다. 과거 고정 ROE/2R 예약비용 진입 조건은 신규 계획에서 대체하고 기존 v1 포지션 계획은 유지한다. 계좌 위험0.5%/명목200/비용0.40/5–10배/원장/세션은 유지한다. 영속 진단은 배포 이후 최대24 UTC 시간 버킷만 집계하며 누락된 과거를 만들지 않는다. [변경·검증·한계](verification/virtual400-structural-plan/RESULT.md). 코드·로컬 검증 완료이며 이 커밋 시점 CI/배포는 pending이다. 역사 BTC 비교는 진입계획 호환성만 확인했고 매일 거래/하루5–10% 수익성은 미검증이다. 이 v13이 아래 과거 정책과 충돌하면 우선한다.

## 최신 지시 — 매일 트레이딩 및 계좌 하루 순수익 5~10% 목표

사용자의 핵심 목표는 시장의 과거 자료 분석을 실제 매매와 비용차감 손익으로 연결하는 것이다. 이전 감독의 포지션 증거금 ROE 해석은 이 목표를 대신하지 못하므로 정정한다. 상세 실제26시간45분 거래0 증거·정책 불일치·개발 수용기준은 [CCC_DAILY_TRADING_OBJECTIVE.md](CCC_DAILY_TRADING_OBJECTIVE.md)를 따른다. 목표는 수익보장이 아니며 검증·달성 상태를 분리한다.
P0는 영속 미거래 원인/단계 집계→현재전략과 목표/위험/빈도/노출의 양립성 검증→과거실데이터 OOS/비용stress를 거친 전략개선→자연 PAPER 거래/순정산이다. 현재 영속 집계와 수익성검증 미완료를 숨기지 않는다. 검증기반 전략·threshold 개선은 허용되며 과거 assistant의 기준완화 일괄금지를 개선금지로 해석하지 않는다. 무근거 강제주문/허위신호/비용0대체/손실삭제/위험목표만보고 자동증액은 금지한다.
매보고는 실제거래/순손익·일수익·무거래시간·상위차단원인·다음수정을 우선한다. 기존기한·원장·PAPER/LIVE/예산·5~10배·손절·모드선택을 유지한다. 아래 역사 기록과 충돌하면 이 v12가 우선한다. 이번 문서수정은 전략구현/배포/목표달성이 아니다.

이번 단일 writer 예약은 완료 인계에서 해제하며 기존 일정·원장·자본·LIVE 잠금·예산은 유지한다.

## 새 사용자 지시 반영

1. 감독 세션은 여기서 받은 명확한 개발 요구·일정 변경을 같은 응답 작업 중 이 계약과 기존 자동화 prompt에 반영한다. 같은 승인을 반복 요청하지 않는다.
2. 버전·적용 시각·변경 내용·유지하는 제약을 기록하고 저장 후 readback으로 확인한다. 저장 실패를 적용 완료로 보고하지 않는다.
3. 실행 자동화는 시작 시, GitHub push 직전, 유료 발주 또는 배포 직전에 최신 자동화 prompt와 이 문서를 다시 읽어 버전 변경을 확인한다. 중간 변경은 다음 안전한 경계에서 반영한다. 기존 실행 중인 작업에 대한 즉시 interrupt/실시간 전달을 보장하지 않는다.
4. 요구가 충돌하거나 실금융·추가 비용 등 기존 승인을 확장하면 그 항목만 보류한다. 독립적인 개발·시험은 계속한다.
5. 이 문서와 자동화 prompt가 다르면 사용자 지시의 출처·버전·시각을 확인한다. 오래된 제한 때문에 전체 개발을 멈추거나 더 위험한 해석을 임의 채택하지 않는다.
6. 각 보고에 적용한 감독 지시 버전과 적용/미적용 변경을 명시한다.
