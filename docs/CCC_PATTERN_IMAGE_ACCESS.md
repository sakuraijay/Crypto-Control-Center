# CCC 차트 사진 수동 분석 — 일반 사용자 접근

사진 선택·미리보기·수동 분석 요청에는 별도 운영자 PIN이 필요하지 않는다.
PIN 입력·안내·필수 검사·버튼 의존성·요청 헤더·이 경로의 서버 PIN
미들웨어만 제거한다. 계정 PIN, 지갑, 실자금, 주문, 관리자 인증은 유지한다.

## 현재 가능한 동작

- 브라우저에서 PNG·JPEG·WebP를 선택하고 실제 파일 헤더와 해독 결과,
  8 MiB 상한, 640×360 이상 / 4096×4096 이하 크기를 검증한다.
- 15분·1시간·4시간 슬롯 중 1~3개를 선택하고 심볼·거래소·시간대를
  확인하면 PIN 없이 수동 분석 버튼을 누를 수 있다.
- 원본 이미지·파일명·미리보기 URL은 서버로 보내거나 저장하지 않는다.
  분석 버튼을 누를 때 허용된 이미지 메타데이터만 전송한다.
- 이미지 분석 제공자는 아직 연결되지 않았다. 서버는 정상 형식의
  PIN 없는 요청에도 `503 IMAGE_ANALYSIS_NOT_CONFIGURED`를 반환한다.
  이는 인증 실패가 아니며 실제 패턴 분석이 완료되었다는 뜻도 아니다.

## 유지하는 보호

서버는 IP별 분당 8회, 제한된 메모리 사용, 4KB JSON 본문, 압축 거부,
엄격한 필드·크기·형식·시간대 검증, 준비 상태와 `Cache-Control: no-store`를
유지한다. 클라이언트의 중복 요청 방지, 요청 중 잠금, 시간 초과,
재시도 대기와 `Retry-After`, 제공자 미연결 시 같은 입력 반복 차단도 유지한다.

외부 제공자 호출·유료 분석·원본 이미지 외부 전송은 추가하지 않는다.
제공자 연결에는 별도 제공자·비용 한도·외부 전송 승인과 비용 제어가 필요하다.
시각적 결과가 생기더라도 주문 실행 권한과는 분리한다.
