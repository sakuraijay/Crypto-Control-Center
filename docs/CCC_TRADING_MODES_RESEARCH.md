# CCC 단타·중기 스윙 목표와 비교 검토

2026-09-21 / CCC-SUPERVISION-20260921-10

## 사용자 요구와 적용 의미

- 단타: 12시간, 목표 수익 5~10%.
- 중기 스윙: 1~3일, 목표 수익 10~20%.
- 손절은 10% 이내를 목표로 제한하며 사용자가 단타/스윙을 선택한다.
- 비슷한 자동 매매 프로그램의 수익·손절 설정을 비교하고 CCC에 적합한 값을 검토한다.

**수익률 기준은 우선 포지션 초기 증거금 대비 비용 차감 순수익률(ROE)로 해석했다.** 사용자가 계좌 전체 수익률을 뜻했다고 정정하면 이 의미를 다시 설계해야 하며 계좌 위험 예산을 묵시적으로 확대하지 않는다. 이 가정은 사용자 확정 발언과 구분한다.
예를 들어 증거금 $20 포지션의 순수익 15%는 $3이며, 계좌 $400 대비는 0.75%다. 일별 계좌 수익, 레버리지 적용 전 가격 변화율, 개별 거래 ROE를 섞어 표시하지 않는다.

손절은 진입 전 위험 제한과 청산 트리거다. 갭·시세/서버 지연·슬리피지·급변하는 비용 때문에 실현 손실을 항상 10% 안에 보장할 수 없다. PAPER에도 관측 가격과 비용을 사용하고 손실을 -10%로 잘라 기록하지 않는다.

## CCC 초기 PAPER 시험 설정

| 선택 | 사용자 목표 범위 | 현재 시험 익절 | 손절 상한 | 보유시간·전략 |
| --- | --- | --- | --- | --- |
| 단타 / INTRADAY | 순 ROE 5~10% | 7.5% | 순 ROE 3% 이내 사전 제한 | 최대 12시간. 기존 추세 눌림·변동성 돌파·박스권 회귀 중 유효 신호 |
| 중기 스윙 / SWING | 순 ROE 10~20% | 15% | 순 ROE 5% 이내 사전 제한 | 최대 72시간. 기존 4h/1h/15m 추세 눌림 신호만 허용 |

7.5%와 15%는 요청 범위의 중간값이고, 3%와 5%는 각각 2.5:1·3:1 목표 손익비를 검토하기 위한 출발점이다. **수익성이 입증된 최적값이 아니며**, 상대적 성과를 비교한 실데이터 walk-forward 결과는 아직 없다. 1~3일은 예상 운용 구간/최대 보유시간이며 손절·익절을 위해 하루를 억지로 기다리지 않는다. 시간 초과 시 수익 여부와 관계없이 정상 청산을 요청한다. 거래를 억지로 발생시키지 않는다.

실행 원칙:

1. 서버에 저장한 선택을 다음 신규 진입에 적용한다. 첫 ACTIVE 실행의 미설정 상태에는 단타 시험값을 영속 저장하며, 훼손된 설정은 자동 기본값 복구하지 않는다. GET/브라우저 재접속은 설정을 쓰지 않는다.
2. 선택 변경은 운영자 인증 및 이전 설정 시각 비교 후 같은 worker 잠금 아래 저장한다. START/STOP, 가상 시드·손익·HWM, 실제 지갑을 변경하지 않는다. 이전 웹페이지의 오래된 저장 요청은 충돌 처리한다.
3. 각 진입은 모드·ROE 기준·진입가·구조적 손절·규모·레버리지·비용 여유·최대 종료시각을 불변 결정 원장에 기록한다. 이후 선택 변경/프로세스 재시작에도 포지션은 이 기록으로 관리한다. 기존 모드 도입 전 포지션은 기존 SL/TP를 유지한다.
4. 기존 계좌 거래당 위험 0.5%, 하루 손실·HWM·신뢰도·횟수·명목노출200·증거금100·비용0.40·레버리지5~10 규칙을 유지한다. 구조적 손절을 축소하거나 노출을 확대해 ROE 목표를 맞추지 않는다.
5. 기존 위험 사이징 후, 선택한 손절 ROE를 만족하는 5~10배 정수 배수를 선택한다. 필요하면 증거금 비중을 높여 배수를 낮추며, 5배에서도 불가능하면 `MODE_STOP_ROE_OR_MIN_LEVERAGE`로 진입 거절한다.
6. 최대12/72시간의 funding/borrowing 추정을 기존 센트 올림 PAPER 비용 모델로 계산한다. 진입+청산+보유비용이 $0.40를 초과하거나 rate가 없으면 거절한다. 이후 실제 관측 변화와 추정 차이는 수익성 검증의 별도 스트레스 항목이다.
7. 비용 차감 목표/사전 위험의 비율은 최소2배여야 하며, 전략의 예상 순이익에서 보유비용을 뺀 값이 목표보다 작으면 `MODE_TARGET_EXCEEDS_SIGNAL_EDGE`로 거절한다. 단순 목표값 변경이 새로운 시장 우위를 만든다고 주장하지 않는다.
8. 실행기가 결정 원장의 계획을 다시 계산·검증한다. 관리 틱은 기존 가격 손절을 우선하고, 신규 모드 포지션은 비용 차감 ROE 익절/손절·시간 종료로 정상 청산·정산한다. 계획/비용이 훼손된 모드 포지션은 보호 청산을 요청한다. Risk REDUCE70 후에는 잔여 포지션의 비례 증거금 기준으로 보호하며 기존 정산 기록을 지우지 않는다.

## 최적화 검증 및 승격 기준

현재 확보된 기능 시험은 합성 REPLAY이며 역사적 수익성 백테스트가 아니다. 실행 로직 통과와 투자 성과 검증을 구분한다.

- 데이터: 거래 대상 BTC/ETH/SOL의 시간 순서가 보존된 실제 확정 캔들, 조회 출처·기간·결측을 기록한다. 추세 상승/하락/박스권/급변 구간을 나누고 미래 캔들·성과를 신호에 사용하지 않는다.
- 비용: 진입/청산·불리한 체결·funding/borrow·최소 주문·갭·시세 지연을 포함한다. 보유기간별 비용과 2배 비용 스트레스를 비교하며 정체불명 값이나 미확인 비용을0으로 대체하지 않는다.
- 후보: 단타 TP 5/7.5/10%, SL 2/3/4%; 스윙 TP10/15/20%, SL3/5/7%. 이는 실험 후보이며 실행 프리셋을 즉시 바꾸는 승인이나 최적값이 아니다. 구조적 손절·5배 최소·계좌 위험·비용·순손익비 제한을 모두 통과한 거래만 비교한다.
- 평가: 학습/선택 구간과 미사용 검증 구간을 시간순 분리하고 여러 walk-forward 구간에서 순 기대값, 최대낙폭, profit factor, 승률, 평균 손익비, 보유시간, 거래 수와 무거래 비율을 함께 기록한다. 최소 거래 수·관측 기간과 불확실성은 시험 계획에 사전 고정하고 적은 표본의 높은 수익을 우승으로 선정하지 않는다.
- 승인 판단: 검증 밖 구간과 비용 스트레스에서 손실/낙폭이 견딜 수준이며 인접 파라미터에서도 결과가 안정적인지 본다. 충족 못하면 `NO_VALIDATED_PRESET`이다. 실현 수익을 보장하거나 매일 목표를 달성한다고 표시하지 않는다.
- 이후 자연 PAPER 체결에서 검증하고, 초기 고정 프리셋 대비 개선 증거가 있을 때 버전 변경한다. 전체 재학습/탐색을 매시간 반복해 비용을 늘리지 말고 재사용 가능한 데이터와 배치 시험으로 진행한다.

10월1일18:00 PHT Alpha/Beta의 기존 가상 매매 lifecycle/사용성/복구 검증은 계속 최우선이다. 그 날짜까지 장기 수익성이나 두 전략의 모든 시장 국면 검증을 완료했다고 선언하지 않는다. 새 손절/목표 제약 때문에 무거래가 늘면 사유·비용·전략 적합성을 보고하고 수치를 임의 완화하지 않는다.
