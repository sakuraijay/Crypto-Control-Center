# CCC 차트 스크린샷 수동 참고 — 구현 및 연결 인계

## 소스 복구 경위

이전 로컬 업로드 UI 커밋 `c097f89`는 GitHub 인계 커밋 `fa458f0`의 조상이 아니다.
사용자가 요청한 정확 커밋 동기화는 해당 별도 작업을 포함하지 않았다. 삭제 오류나
프로덕션 기능 완료로 해석하지 않는다. 최신 품질 게이트를 보존하며 UI를 선택적으로 복구한다.

## 실행·보관 경계

- 15분/1시간/4시간별 PNG/JPEG/WebP 선택, 미리보기, 교체, 삭제 및 시간대/종목/거래소 확인.
- 원본은 브라우저 메모리에만 둔다. DB, localStorage, 디스크, 외부 제공자에 저장/전송하지 않는다.
- 분석 버튼을 누르기 전 네트워크 분석 요청은 없다. 현재 서버에는 작은 메타데이터만 보낸다.
- 운영자 PIN은 요청 헤더에만 사용하며 저장하지 않는다. 서버는 기존 운영자 인증,
  요청 크기 제한, 요청 속도 제한, 엄격한 메타데이터 검증을 적용한다.
- 현재 응답은 `IMAGE_ANALYSIS_NOT_CONFIGURED`이다. 가짜 후보·가격·확률·완료봉 판정을 생성하지 않는다.
- 현재 품질 게이트는 입력 메타데이터 검증이지 이미지 OCR이나 38개 OHLC 규칙의 실행이 아니다.
- 결과 표시 계약은 기존 38개 ID의 시각적 후보/불일치/판독불가, 시각적 근거,
  확인 불가능 조건, 상승/하락/중립/미확인 및 시간대 방향 일치/충돌을 위한 것이다.
  실결과를 생성하려면 승인된 제공자 연결과 신뢰 경계 검증이 추가로 필요하다.
- 자동매매, 주문 권한, 세션, 원장, 위험 한도와 연결하지 않는다.

## 미완료: 실제 이미지 판독

2026-10-01 연결 목록/검색에서 승인된 이미지 판독 제공자는 확인되지 않았다.
MiniMax/xAI는 미설정이다. 새 유료 서비스, 자동 충전, 키 변경은 이번 작업에서 수행하지 않는다.

승인 후보: Replit AI Integrations의 OpenAI GPT-5 mini 이미지 입력.
Replit 공식 문서에 따르면 개인 API 키 없이 사용할 수 있지만 제공자 공개 가격으로
Replit 크레딧에서 과금된다. 직접 OpenAI 방식은 별도 키가 필요할 수 있다.

공식 GPT-5 mini 공개 가격은 입력 $0.25/백만 토큰, 출력 $2/백만 토큰이다.
3장과 38개 설명을 포함한 요청이 총 입력 12,000토큰, 출력 6,000토큰이면
예시 비용은 $0.015/요청이다. 입력 24,000 + 출력 12,000이면 $0.030이다.
이는 측정치나 보장 가격이 아니다. 이미지 토큰화, 추론 출력, 응답 길이 및 요금 변경에 따라 달라진다.

필요한 명시적 승인:

1. 제공자/모델 및 이미지 외부 전송·제공자 보관 정책 동의.
2. 권장 시험 상한: 1회 $0.05, 하루 $1, 월 $5, 자동 충전 없음.
   이는 제안일 뿐 아직 승인되거나 집행된 제한이 아니다.
3. 호출 전 보수적 토큰 상한 예약, 이미지 리사이즈, 출력 토큰 제한,
   동시 요청/중복 예약 및 사용량 기반 예산 차단을 구현·검증한 후에만 호출.
   비용 상한 안에서 응답이 불완전하면 판독불가/실패로 처리하며 결과를 보충하지 않는다.

미완성 봉, 흐림, 차트 아님, 종목/시간대/거래소 불일치, 보이지 않는 가격·거래량·완료봉 상태는
한계로 명시한다. 시각적 유사성은 정확 OHLC 검증이나 수익 확률이 아니다.

## Figma 인계

기존 한국어 CCC 패턴 화면 상단의 3시간대 첨부/확인, 미리보기·교체·삭제,
PIN·수동 분석 버튼, 입력 오류/진행/인증 실패/속도 제한/미연결 상태 및
향후 38개 결과·방향 충돌 표시를 Figma 컴포넌트와 반응형 화면에 반영해야 한다.
Figma 원본은 수정하지 않는다.

## 검증 기록

2026-10-01 전체 타입 검사 통과. 전체 테스트는 API 196파일/2,994개,
웹 41파일/504개 통과. 신규 API 메타데이터 테스트 11개와 웹 helper 테스트 15개,
기존 품질 게이트 테스트 10개를 포함한다.

개발 브라우저에서 3시간대 첨부/확인/교체/삭제, 버튼 전 요청 없음,
실제 잘못된 TEST PIN의 401, 이중 클릭 1회 요청, 잘못된 이미지·크기 거절,
지연 decode 교체 경쟁, 화면 재진입 시 첨부/PIN 해제, 390px 모바일 화면을 검증했다.
미연결 503 화면은 브라우저 인터셉트 fixture로 검증했고,
서버의 인증 후 실제 503 계약은 격리 HTTP 테스트에서 검증했다.
실제 이미지 판독이나 성공 분석을 수행한 기록은 없다.
브라우저에서 거래/설정/가상 세션 시작·재설정 작업은 하지 않았다.

배포 구조 검증 및 `build:deploy`가 통과했다. 게시하거나 원격 브랜치에 push하지 않는다.
