# PAPER 진입 정책 v8 — 게시 전 인계

## 운영에서 확인한 문제

2026-10-01 읽기 전용 운영 조회에서 마지막 신규 진입 이후 4,424분
(약 73.7시간)이 경과했다. 당시 위험 상태는 `NORMAL`, 미청산 포지션은 0개였다.
현재 후보의 탈락 사유에는 `VOLATILITY_OUTSIDE_STOP_RANGE`와
`WEAK_MOMENTUM`이 포함됐다.

기존 비교는 후보 2,000개 / 완료 쌍 2,000개 / 필터 통과 0개에서
`CAP_REACHED`로 정지했다. 이는 v8의 성과 증거가 아니다.
종전 진단은 일부 품질·손익비 탈락 사유를 집계하지 않았으므로 과거
탈락 빈도와 미기록 특징값은 사후 재구성하지 않는다.

v7의 목표 2R, 왕복비용 C, 비용 차감 후 손익비 1.5 조건은
`(2R-C)/(R+C) >= 1.5`, 즉 `R >= 5C`이다.
운영 표본 UNI의 명목 $688.7929910125, 가격 위험 약 $5.51034,
추정 왕복비용 $1.1979928629는 순손익비 약 1.46436으로 탈락한다.
다만 모든 2,000개가 이 조건 하나로 탈락했다고 주장하지 않는다.

## 바뀌는 부분

- 정책 `virtual400-daily/v8`, 신호 `paper-entry-signals/v8`,
  계획 `virtual-daily-structural/v1`로 기존 정책/거래와 구분한다.
- 종목 자신의 완료봉 변동성 분포를 사용한다. 추세·완료봉 돌파·횡보
  반전 각각의 설명 가능한 점수와 임계값을 별도로 평가한다.
- 손절은 관측한 가격 구조, 목표는 기존 스윙 가격 또는 관측 범위의
  투영과 실제 관측 보유기간 이동폭에 결속한다. 손익비 통과를 위해
  손절을 임의 축소하거나 목표만 늘리지 않는다.
- 단타 1시간 / 스윙 4시간의 보유비용을 포함한다. PAPER 신정책의
  순손익비 하한은 1.0이며 양의 순목표 이익이 필수다. 이것은
  승률·기대수익·수익 보장이 아니다.
- 종전 $2 비용 준비금은 위험액 계산에 그대로 포함한다. 실제 왕복비용은
  별도로 계산하며 $2 초과, 불명, 오래된 비용은 진입을 차단한다.
- 같은 종목·완료봉·공통 가격/평가시각에서 v7/v8을 별도로 평가한다.
  각 정책의 방향·손절·명목에 맞는 비용을 각각 조회하며 비용을
  선형 비례시켜 대체하지 않는다.

## 바뀌지 않는 보호

실자금 실행, LIVE 권한, signer, 키와 relay 경로는 변경하지 않는다.
원금 기준 일손실 5%, 주손실 10%, 누적손실 30%, 평가자산 대비
진입당 위험 최대 1%, 동시 1포지션, 레버리지 5–10배,
명목 최대 $1,000, 증거금 최대 $100, 중복·신선도·원장 보호를 유지한다.
보호조건은 신호점수와 별도로 최종 PAPER 실행기에서 재검증한다.

활성 세션이 flat이고 pending close/unresolved가 없는 경계에서만
새 정책을 적용한다. 적용시각과 이전 정책을 별도 감사기록으로 남긴다.
손실, 입금, HWM, 기간 기준점과 잠금을 초기화하지 않는다.
정책 버전을 바꾸어 같은 완료봉의 중복 주문 방지를 우회하지 않는다.
기존 포지션은 진입 당시의 불변 계획으로 관리한다.

## 비교와 진단의 정직한 의미

- v1 비교 표본은 신정책 적용 후 원본 그대로 보존한다.
- 새 비교는 별도 v2 날짜별 페이지와 누적 체크포인트로 계속 수집한다.
  2,000개는 전체 수집 중지 조건이 아니다.
- 새 비교는 현재 **진입 정책 판정 비교**다. 비용 근거가 없으면 null이며,
  보유시간 미경과와 성과 판정 불명을 구분한다.
- 완료봉 가격 경로 재생을 연결하지 않은 비교의 PnL·기대수익·승률은
  null / `NOT_EVALUATED_NO_CLOSED_CANDLE_REPLAY`다.
  시간이 지났다는 이유만으로 성숙 성과나 성공으로 간주하지 않는다.
- 진단은 종목·정책·완료봉별로 중복 집계하지 않는다. 실제 탈락 특징값,
  임계값, 사유 빈도, 다음 60초 평가 주기의 예정시각을 표시한다.
  예정시각은 보장이 아니며 작업 중지·외부 장애에 따라 달라진다.
- 24시간 이상 무진입은 확인 필요 상태로 표시할 뿐, 강제·랜덤 주문이나
  최소 거래 수, 승격·실자금 권한을 발생시키지 않는다.

## 게시 조건

실제 완료봉 기반 가상 체결·손익·시간 종료·정지/재시작 회귀,
전체 API/web 회귀, 전체 타입 검사, web 빌드, 배포 번들,
별도 settlement/handoff CI를 통과해야 한다.
배포 빌드는 보안 관련 소스와 로컬 Git SHA가 일치해야 하므로
미커밋 상태를 허용하는 우회 설정은 사용하지 않는다.

이 문서와 작업 소스를 GitHub 개발 브랜치에 non-force fast-forward로
보존한다. 기존 PR 병합·강제 push·이력 덮어쓰기를 하지 않는다.
정확한 최종 SHA와 검사 결과는 인계 응답에 기록한다.
**이 요청에서는 게시하지 않는다.** 운영에 v8이 적용되었다고 주장하지 않는다.
