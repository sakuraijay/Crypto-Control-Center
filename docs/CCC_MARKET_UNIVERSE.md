# CCC 자동 종목 선정 — 2026-09-21

지시 CCC-SUPERVISION-20260921-11. 기존 Virtual400은 실제 분석/진입 BTC·ETH·SOL, 정적 실행 시장 메타데이터는7개였다. 별도 SHADOW universe가 있었지만 실행과 연결되지 않았다. 기존 SHADOW의 legacy endpoint/선정 결과를 그대로 실행 권한으로 승격하지 않는다.

## 적용 경로

1. 기존 읽기 전용 GMX transport로 Arbitrum `/v1/markets/info` 전체 목록 조회. 성공4분 캐시, 실패1분 재시도, 동일 요청 병합. 새 유료 서비스나 LLM 호출 없음.
2. 설치된 공식 `@gmx-io/sdk`의42161 시장/토큰 주소·소수점 메타데이터와 결속. 미확인/주소 불일치/중복/비활성/spot 시장은 제외. zero-index swap pool을 ETH 시장으로 오인하지 않는다. 같은 심볼의 자산 주소가 모호하면 시세를 사용하지 않는다.
3. poolValueMin $1m 이상 및 주소가 일치하는60초 이내 실제 시세 필요. 이 풀 자산 가치는 실제 방향별 주문 가능 유동성이나 수익 보장이 아니다. 최종 비용/impact/정확한 명목금액/위험 검증이 별도로 필요하다.
4. 자산별 적격 풀이 여러 개면 poolValueMin이 가장 큰 풀(동률 주소순)을 선택. 종목명 화이트리스트 없음. 검증된 SDK에 없는 신규 상장은 SDK_METADATA_UNVERIFIED로 관측하되 검증 전 실행 금지.
5. 적격 종목을 최근 분석 시각 순으로 세 종목씩 분석. 동일3종목 영구 고정 방지; cursor는 session별 DB에 저장해 재시작 후 계속한다. 전체가 매분 정밀 분석되는 것은 아니다. 대상 수 N이면 이상적인1분 주기에서 대략 ceil(N/3)주기에 한 번이며 API 지연/worker/위험 gate로 더 늦을 수 있다.
6. 기존 확정4h/1h/15m 캔들·regime/lifecycle, 단타/스윙 전략과 신뢰도·선정점수, 비용 차감 순이익/ROE/구조적 손절·5~10배·계좌위험·중복·보호 gate 적용. 상위 전략 점수도 수익 확률/보장은 아니다. 한 주기의 유효 후보 중 선택하며 시장 전체 최적 거래를 수학적으로 보장하지 않는다.
7. 비용은 선택한 정확한 market 주소로 조회·검증한다. 기존 Standard/Canary/LIVE 정적 시장 권한을 확대하지 않는다. 신규 PAPER 종목 가격은 서버 공식 주소 결속 캐시에서 조회하며 상장/분석 목록에서 빠져도 기존 포지션의 가격 보호 경로를 없애지 않는다.
8. runtime.universe는 목록 총수·적격심볼·선정시장·제외사유·실제batch·관측시각·완전성 제공. 기존 AI 활동 패널은 실제batch를 표시한다. 브라우저는 별도 실행 루프가 없다.

## 제한과 수용 기준

GMX Arbitrum의 검증 가능한 무기한 시장이 범위다. 전체 암호화폐 시장·다른 거래소/체인의 모든 코인을 거래하는 기능은 아니다. 거래소를 추가하려면 별도 실행·정산·수수료·인증 통합이 필요하다. 알려지지 않은 토큰의 소수점을 추정해 잘못된 가격으로 진입하지 않는다.
기존 원장·400자본·HWM·세션·선택모드 및 최대노출/손실한도 유지. 운영비는 전체목록의 경량 조회만 추가하며 정밀 분석은 기존3개batch 한도 유지. 목록 실패나 적격0건은 신규진입을 차단하고 실제 이유를 노출한다. 실패를 정상0시장/가짜기회로 표시하지 않는다.

검증: XRP 신규종목 선정, 정확시장 비용 결속, 잘못된 시장·비활성·spot·메타데이터누락·유동성누락·stale/future/주소불일치 시세 차단, ETH/zero-index 구분, 순환배치 비기아성, 기존세션보존, 실제 PAPER executor의 XRP 합성 OPEN→재시작→TP→비용차감정산 및 기존 회귀. 합성시험은 실제 XRP 체결/수익이 아니다.
최종 CI/배포/runtime 증거는 완료 인계에서 기록하며 이 문서 작성 시에는 미확인이다. 기존 COST_UNAVAILABLE 해결·자연 OPEN/CLOSE/정산·장기 수익성·Alpha/Beta 수용은 각각 별도 검증한다.
