---
name: PAPER 신호 완화와 손실 보호 분리
description: PAPER 손실 연속 횟수의 진입 정지와 시장 신호 선별을 계좌 보호·비용 증거와 분리하는 승인 범위
---

PAPER에서는 연속 손실 횟수만을 이유로 장시간 신규 진입을 막지 않는다. 다음 유효한 기회는 남은 일손실 예산, 개별 손절, 주간·누적 보호 및 미해결 상태를 다시 확인한다. 신호 조건 완화는 LIVE 정책 변경, 손실 삭제 또는 원장 초기화의 승인이 아니다.

**Why:** 사용자가 PAPER 진입 조건을 크게 완화하고 연속 손실만으로 생기는 긴 대기를 제거하도록 승인하면서, 일손실 5%와 기존 계좌 보호·기록 보존은 유지하라고 명시했다.

**How to apply:** 신호 적격성, 계좌 안전 차단, 비용 적격성을 별도 판단·진단한다. 선택된 신호가 없어서 손절도 없는 경우를 가격 방향이나 손절 거리 오류로 해석하지 않는다. 실제 방향·거리 오류는 계속 차단한다.

새 PAPER 패턴 주도 정책에서는 38개 차트·캔들 패턴 각각이 독립 진입 후보를 생성한다. 기존 품질·추세·모멘텀·국면·변동성·비용 후 손익비는 보조 순위·설명 정보이며, 패턴 탐지 전이나 실행 후 숨은 전략 거부 조건으로 사용하지 않는다.

**Why:** 사용자가 38개 패턴의 독립 전략화를 추가 지시하면서 비용 후 손익비 같은 기존 선별값도 보조로 바꾸라고 명시했다. 이전 정책의 손익비 하한 유지 결정은 새 패턴 주도 정책에 적용하지 않는다.

**How to apply:** 패턴마다 확정·방향·트리거·관측 무효화 손절·청산 규칙을 정하고 완료봉과 확정 pivot만 사용한다. 중립은 후속 완료봉의 확인까지 대기하며, 동일 종목·시간대·패턴 사건의 재주문과 설명 없는 충돌 방향 선택을 금지한다. 일손실 5%, 주간·누적 보호, 위험 1%, 동시 1포지션, 레버리지 5–10배, 명목 $1000·증거금 $100, 유효 시세·실제 추정 비용·개별 손절·중복 방지는 실행 보호로 유지한다.

가정 기반 재생은 실제 비용 후 성과나 수익성을 입증하지 않는다. 손익비를 보조로 전환하는 것은 비용 증거를 0으로 대체하거나 기대수익을 만들어내는 승인이 아니다.

**Why:** 과거 시점의 방향별·정확 주문 규모별 비용과 당시 계좌 상태가 없으면 시간순 재생도 실제 경제성을 입증하지 못한다. 사용자가 가짜 기대수익을 금지하고 샘플 한계를 명시하라고 지시했다.

**How to apply:** 구조적 후보·차단·진입 수와 가정 비용의 모델 결과를 분리하고 실측 순손익·낙폭·승률은 증거가 없을 때 UNAVAILABLE/null로 둔다. 새 정책과 옛 원장을 구분하며 원장·손실·입금·거래를 재작성하지 않는다. 실제 돈·권한·키·새 유료 API·PR 병합·강제 푸시를 변경하지 않고, 스크린샷/PIN 제거 작업을 보존하며 검증 전 게시하지 않는다.
